Blackjack Probability

Additional Features
Real-time statistics tracking for score, win rate, and streaks
Probability-based decision hints using Monte Carlo simulations
Simulation engine that estimates expected outcomes for different actions
Responsive and visually polished interface compatible with desktop and mobile

Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Python (FastAPI, NumPy, Matplotlib)

Tools: Git, VS Code

How to Run
pip install -r requirements.txt
python main.py
Then open your browser at:
http://localhost:8000
